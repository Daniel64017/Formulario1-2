# Projeto: Praticando HTML e CSS

Este repositório contém alguns dos meus primeiros projetos desenvolvidos durante o aprendizado de HTML e CSS. Ele inclui:

- Um site básico (`Daniel.html`) com estrutura de conteúdo simples.
- Dois formulários personalizados feitos com HTML e estilizados com CSS.

O objetivo deste repositório é demonstrar meus primeiros passos na criação de páginas web e a aplicação prática dos conceitos fundamentais de desenvolvimento front-end.

## Estrutura do Projeto

- `Daniel.html`  
  Página web básica com títulos, parágrafos e elementos de estrutura. Criado durante as aulas iniciais de HTML.

- `formulario.html`  
  Primeiro formulário criado para coletar informações básicas do usuário.

- `style.css`  
  Arquivo de estilo utilizado para estilizar as páginas e formularios, aplicando cores, espaçamentos, fontes e organização visual.

## Tecnologias Utilizadas

- HTML5
- CSS3
